# Проверка терминологии и исходников

Текущая очистка относится ко всей рабочей версии репозитория. Внутренние файлы, комментарии, идентификаторы, тесты, документация и вложенные исходные архивы больше не считаются исключениями из правила удаления имён поставщиков и внутренних производственных сокращений.

Старые таблицы с допустимыми служебными совпадениями удалены. Идентификаторы и адреса интеграции переименованы нейтрально, связанные ссылки и ключи схем согласованы. Исходный архив исключён из репозитория. Поиск в истории Git не подменяет проверку текущей версии исходников.

Для проверки используются исходные файлы и отдельно собранный статический сайт. Неизменяемые integrity-хеши сторонних пакетов и стандартные параметры инструментов не являются именами поставщиков; их нельзя произвольно исправлять ради буквенного совпадения.

## Технические термины

- «Рабочая точка» остаётся однократным определением внутри подробного раздела статьи о данных для подбора компрессора. В hero, карточках и CTA термин не используется.
- «Узел» допустим внутри технического описания конструкции, интеграции, безопасности или применимости документа. Основной объект продажи — компрессор либо бустер.
- `skid` допустим вторично после понятного русского определения системы на общей раме. Это вариант комплектации.
- Модульная компоновка также является вариантом исполнения, а не обязательным продуктом.

Публичный аудит выполняется командой `python3 scripts/audit-public-copy.py` после `npm run preview:build`. Полная репозиторная проверка дополнительно охватывает код, имена файлов и документацию. Новые результаты сборки, тестов и поиска фиксируются в отчёте текущего прохода.

## Числовые утверждения

Неподтверждённые диапазоны расхода и давления не публикуются. SVG-координаты, номера шагов, даты и индексы химических формул не являются характеристиками компрессора. Оставшиеся числовые определения, примеры и withheld equipment values разобраны в [QUANTITATIVE_EVIDENCE](QUANTITATIVE_EVIDENCE.md).

Финальная приёмка текущей очистки: [REPOSITORY_CLEANUP](REPOSITORY_CLEANUP.md).
