**H1:** Компрессоры для технологических газов

**Lead:** Подбираем компрессоры и бустеры под ваши параметры. N₂, He, SF₆, CO₂ и другие технологические газы. Подбор по давлению на входе, требуемому давлению, расходу и режиму работы.

**Primary CTA:** Подобрать компрессор

**Secondary CTA:** Отправить параметры

Hero показывает компрессор. Длинный перечень опций перенесён ниже. Главная и global metadata используют порядок N₂, He, SF₆, CO₂, другие технологические газы. H₂/O₂ остаются отдельными техническими направлениями. Упоминание SF₆ не создаёт новую модель, gas-specific спецификацию или контракт RFQ: для такой задачи уточняется состав газа.

## Параметры и комплектация

**H2:** Начнём с 5 основных параметров

Укажите газ, давление на входе, требуемое давление на выходе, расход и режим работы. Этого достаточно, чтобы начать подбор компрессора. Остальные параметры уточним в процессе проработки.

Карточки: Газ; P₁ — давление на входе; P₂ — требуемое давление; Q — расход; Режим работы.

Сразу следом отдельный блок **«Комплектуем компрессор под задачу»**: «После выбора компрессора определяем необходимую комплектацию — от базового исполнения до комплектной системы на общей раме».

Последовательность: **КОМПРЕССОР → + НЕОБХОДИМЫЕ ОПЦИИ → КОМПЛЕКТНАЯ СИСТЕМА**. Охлаждение, КИП, арматура, ресивер, автоматика и обвязка имеют отметку «По необходимости». Необязательность всех опций указана явно. На мобильном progression вертикальный.

- «Проверить рабочую точку» на последнем шаге RFQ → «Проверить параметры подбора».
- «Рабочая точка для инженерного подбора» → «Параметры для подбора компрессора».

RFQ сохраняет проверку единиц, базы давления, P₂ > P₁, расхода, газовых уточнений и отдельного согласия. Raw query identifiers заменены понятными названиями с безопасным fallback. Предварительный ответ не обещает конкретную модель, Oil-Free исполнение или комплектность без проверки. GitHub Pages — демонстрация без отправки и сохранения заявки.

## Лазерная резка

`/industries/laser-cutting/` начинается с задачи **«Газоснабжение лазерного станка»**. Раздельно показаны:

- Сжатый воздух: компрессор → ресивер → осушитель → фильтрация → лазер.
- Азот: источник N₂ / генератор → бустер → ресивер → лазер.

Давление, расход и качество газа определяются станком, материалом, толщиной и технологией резки. Азот не назван универсально лучшим. Фиксированных P₁/P₂ нет. При достаточном давлении источника азота бустер может не требоваться; схемы не задают обязательную комплектацию для любого станка.

## Claims и результаты поиска

Ни одного количественного claim о характеристиках компрессоров без evidence не опубликовано. `1–500+ Нм³/ч`, `до 150+ бар`, `15→40` и `15-40` в публичной проекции не найдены. Исходные envelopes остаются во внутреннем draft seed.

`publicProperties()` больше не принимает `engineering-verified` с одним названием источника: обязательны совпадающие статусы, название, HTTPS-ссылка без credentials и страница/раздел. Подлинность и применимость источника требуют инженерной проверки; URL не повышает статус автоматически. Все реальные product properties остаются draft, `productGasSpecs` пуст.

Имена поставщиков удалены из полной рабочей версии репозитория, включая данные, комментарии и документацию. Внутренний seed обезличен, checksum пересчитан по очищенному файлу; исходный архив исключён из проекта. Цифры в обозначениях OF… не выдаются за диапазоны производительности; записи явно draft, не подтверждённые модели Lanfor.

Все оставшиеся числовые определения, примеры, Oil-Free и CLASS 0: [QUANTITATIVE_EVIDENCE](QUANTITATIVE_EVIDENCE.md).

Актуальное правило поиска охватывает весь репозиторий, включая internal, комментарии, тесты и документацию. Старые таблицы, допускавшие сохранение служебных названий, удалены. Требования к техническим терминам описаны в [EDITORIAL_SEARCH_RESULTS](EDITORIAL_SEARCH_RESULTS.md). Числовые характеристики без evidence по-прежнему не публикуются.
