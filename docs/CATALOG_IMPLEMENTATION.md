## Источники, backlog и неподтверждённые claims

Изучены текущие материалы проекта, документы о достоверности, частный seed и три краткие проектные заметки из исходного архива: подбор, бустер/источник, безмасляное сжатие. Полных внешних статей, URL, дат публикации, первичных каталогов и паспортов для сверки в доступных материалах нет. Переработано три проектные заметки; полных внешних публикаций — ноль. Переводы и библиографические сведения не выдуманы.

Новые тексты — самостоятельные качественные объяснения, а не утверждения о подтверждённых характеристиках конкретной модели. Внутренний backlog содержит 14 тем и решения CREATE/UPDATE/MERGE/REJECT после проверки пересечений. Внешняя инженерная рецензия не заявлена как выполненная. Для эксплуатационных решений нужны документы выбранного оборудования и требования площадки.

Пять исходных записей сохранены только во внутреннем registry:

- OF2–OF8/DP
- OF2–OF8/DZ
- OF8–OF30/DP
- OF30–OF500/DP

Сохранены исходные газовые списки, давления на входе/выходе, расход, мощность, утечки, охлаждение, привод и source note. Контрольная сумма seed не изменена: `cc08636523dc579751f154deef9c4f3dbfec686a1f8c16bcf2d42b32f7dc9c7e`. Все записи и candidate links остаются draft; approved gas-specific selection logic отсутствует. SF₆ и смеси не получили совместимость из внешнего списка.

Не опубликованы числовые envelopes, универсальные давления/расходы, мощность, заявленный срок службы/наработка, обещания чистоты, CLASS 0, гарантии Oil-Free для неподтверждённого исполнения, сертификаты и сроки поставки. Контексты оборудования, решений и документов проверяются по публичным allowlist до сериализации и при приёме. Точная source model клиенту не назначается.
