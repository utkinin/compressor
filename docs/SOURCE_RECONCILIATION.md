# Сверка с исходным проектом

Дата: 22 октября 2026 года. Работа началась в пустом checkout по заданию v1.1. Позднее пользователь предоставил исходный scaffold и отдельные спецификации. Они использовались для проверки структуры, намерений страниц и draft-данных, а не как подтверждение характеристик оборудования.

Последующее требование пользователя распространяет очистку на весь проект: внутренние данные, комментарии, ключи, маршруты, тесты, документацию и вложенные архивы. Имена поставщиков и внутренние производственные сокращения в текущей версии репозитория не сохраняются. Исходный ZIP исключён из проекта; пользовательское вложение вне репозитория не является частью исходного кода.

## Что сохраняет реализация

- Путь заказчика: задача → параметры газа → подбор компрессора → необходимые опции → комплектное решение.
- Next.js App Router, server components, минимальные client islands и content repository остаются прежними.
- Пять исходных draft-семейств: OF2–OF8/DP, OF2–OF8/DZ, OF8–OF30/DP, OF30–OF500/DP, OF60–OF200/DP. Их URL `/equipment/of…/` сохранены; обозначения не истолкованы как подтверждённые диапазоны характеристик.
- Внутренние draft-значения, газовые списки и статусы сохранены в `src/content/internal/manufacturer-seed.ts`. Источники описаны нейтрально. SHA-256 очищенного файла: `cc08636523dc579751f154deef9c4f3dbfec686a1f8c16bcf2d42b32f7dc9c7e`; запись есть в `docs/source/SHA256SUMS`. Это не checksum побайтной копии первоначального пользовательского исходника.
- Каталожный PDF, страницы, паспорта и утверждённые расчёты не предоставлены. Название исходного документа не повышает статус чисел до подтверждённых. Семейства не получают универсальной газовой совместимости.
- `ProductFamily` и `ProductGasSpec` разделены. Подтверждённые gas-specific specs отсутствуют. Категории оборудования и draft-семейства не смешиваются.
- Все 16 статей Knowledge Hub, related content и существующие canonical intents сохраняются. Конечные legacy aliases не входят в canonical sitemap.
- Публичный порядок газов на главной и в global metadata: N₂, He, SF₆, CO₂ и другие технологические газы. Упоминание SF₆ не является новой спецификацией оборудования или расширением RFQ gas model.

## Нейтральные адреса интеграции

- `/solutions/equipment-integration/` — компрессор для встраивания в оборудование.
- `/industries/equipment-manufacturers/` — изготовителям оборудования.
- `/cases/compressor-integration/` — типовой сценарий встраивания компрессора.
- `integration` — внутренний ключ инженерной схемы.

Старый отдельный alias с удаляемым служебным обозначением исключён. Совместимость с ним не сохраняется через скрытые строки, комментарии или redirects.

## Статусы и достоверность

Редакционные статусы: draft/review/approved/published. Вновь созданные материалы остаются review. Статусы полей: engineering-verified/source-transcribed/draft. Ни статус, ни нейтральное название источника не заменяют реальный evidence record и инженерное согласование.

Исходные контакты и краткие реквизиты не утверждены для оператора персональных данных нового сайта. Их не включают автоматически. Специальная чистота, Ex, oxygen-service, food/medical и другие исполнения требуют документов и не следуют из категории компрессора.

## GitHub Pages

Подход существующего reference-проекта проверен через Git: отдельный статический просмотр без серверной обработки. Для текущего проекта используется `/compressor` basePath и browser-only RFQ demo. Серверный API доступен только в полноценной Next-сборке. Публикация и проверка внешнего HTTPS считаются выполненными после реального подтверждения, а не после локального export.
